Browser minimal untuk macOS

Browser yang menyatu dengan notch MacBook

NotchBrowser membuka pratinjau browser saat Anda mengarahkan kursor ke notch. Klik panel untuk berinteraksi, lalu kecilkan kembali saat selesai.

Unduh NotchBrowser untuk Apple Silicon · Lihat source code NotchBrowser di GitHub

Browser macOS dengan panel yang tetap menempel di atas

NotchBrowser menggunakan satu panel yang sama untuk tampilan notch compact dan browser expanded. Panel mengembang ke bawah tanpa membuka window browser terpisah. Jika Mac tidak memiliki notch fisik, panel muncul di tengah tepi atas layar utama.

  • Hover membuka pratinjau tanpa mengambil fokus keyboard.
  • Klik panel untuk mulai mengetik dan berinteraksi dengan halaman.
  • Kelola tab, masukkan URL atau kata pencarian, dan gunakan navigasi kembali/maju.
  • Tab dan halaman tetap hidup saat panel dikecilkan.

Kompatibilitas dan instalasi

Aplikasi memerlukan macOS 13 atau lebih baru. Unduhan rilis saat ini ditujukan untuk Apple Silicon (arm64). Aplikasi belum dinotariskan oleh Apple.
