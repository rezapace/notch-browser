# NotchBrowser v0.5.0

Rilis publik pertama: browser macOS minimal yang menyatu dengan notch.

## Fitur

- Satu panel berubah dari compact notch menjadi browser, tetap menempel ke tepi atas layar.
- Kontrol hanya tab (+/×), URL, previous, dan next; border tipis dan area kamera aman.
- Hover membuka preview tanpa mengambil fokus keyboard. Klik untuk berinteraksi.
- Tab/WebView tetap hidup saat expand/collapse.
- ⇧⌘W kembali ke notch, ⌘L fokus URL, ⌘T/⌘W mengelola tab, dan ⌘Q keluar.
- Source, dokumentasi, serta script build/test/DMG tersedia dalam repository.

## Download dan instalasi

**Asset:** `NotchBrowser.dmg` — Apple Silicon (arm64), macOS 13+.

1. Tutup versi lama dengan ⌘Q jika masih berjalan.
2. Buka DMG dan seret `NotchBrowser.app` ke Applications.
3. Eject DMG, lalu jalankan dari Applications.

Aplikasi menggunakan **ad-hoc signing, belum notarized**. Jika Gatekeeper memblokir, gunakan System Settings → Privacy & Security → Open Anyway hanya jika Anda mempercayai sumber aplikasi. Tidak perlu menonaktifkan Gatekeeper secara global.

`SHA256SUMS` disertakan untuk memeriksa integritas DMG. Setelah kedua file diunduh ke folder yang sama, jalankan `shasum -a 256 -c SHA256SUMS`.

## Validasi dan batasan

Build release, tes otomatis, signature app, checksum DMG, dan resource dari volume read-only diverifikasi sebelum publikasi. Ini tidak menggantikan uji manual semua perangkat, situs, IME, atau konfigurasi fullscreen/monitor.

- Binary bukan universal; versi Intel belum disertakan.
- Tab belum direstore setelah quit/relaunch.
- Halaman tersembunyi dapat tetap menjalankan JavaScript/audio.
