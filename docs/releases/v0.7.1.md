# NotchBrowser v0.7.1

## Perubahan

- Refresh UI lebih terarah: perubahan judul hanya memproses label tab/judul window, bukan address bar dan tombol back/forward. URL tetap memperbarui judul fallback ketika judul halaman kosong.
- Navigasi tab background dan callback tab tertutup tidak mengulang timer auto-hide toolbar aktif. Kontrol yang sudah tersembunyi/dipin tidak menjadwalkan hide baru.
- Editing URL, History API, Escape, dirty state saat kontrol tersembunyi, profil WebKit persisten, dan konfigurasi popup tetap dipertahankan.
- Probe pengembang baru membandingkan WKWebView minimal dengan shell notch pada ukuran viewport yang sama. Tidak ada injeksi benchmark, modifikasi JIT/GPU, atau fitur benchmark khusus di aplikasi release.

## Validasi dan batas pengukuran

- 22 kelompok tes UI/lifecycle/loading, termasuk KVO judul nyata, `pushState`/`replaceState`, proteksi input, dan navigasi background.
- Tiga pemeriksaan resource relokasi, dua smoke test probe engine melalui HTTP loopback, build release, pemeriksaan path build, signature, dan validasi DMG.
- Counter jalur refresh hanya dikompilasi pada test runner, tidak dalam app distribusi.
- Tiga run wrapper per versi: median constructor 3,81 → 3,82 ms; presentasi 10 tab 0,013 → 0,012 ms; footprint proses utama 18,50 → 18,47 MiB.
- Median first load fixture justru 30,93 → 34,44 ms; repeat 8,73 → 8,48 ms. Sampel kecil ini tidak membuktikan perbaikan/regresi website. Waktu loading bukan first paint; footprint tidak termasuk subprocess WebKit.

Patch mengurangi pekerjaan UI yang tidak relevan, **bukan klaim peningkatan skor Speedometer atau menutup gap terhadap Chrome**. Mask notch, forced layout, dan konfigurasi engine belum diubah karena tidak ada bukti profiling yang cukup. Detail: [performa dan probe engine](../performance.md).

## Install / update

```sh
brew install --cask rezapace/notch-browser/notch-browser
```

Untuk pengguna Homebrew yang sudah memasang aplikasi, keluar dengan **⌘Q**, lalu:

```sh
brew update
brew upgrade --cask rezapace/notch-browser/notch-browser
```

DMG release: **Apple Silicon (arm64), macOS 13+**, build 8. Signing masih ad-hoc, belum notarized. Tes perangkat/visual tetap diperlukan. [Panduan Homebrew](../homebrew.md).

## Catatan Gatekeeper

Jika muncul:

> Apple could not verify “NotchBrowser.app” is free of malware that may harm your Mac or compromise your privacy.

Utamakan **System Settings → Privacy & Security → Open Anyway**, hanya jika mempercayai sumber release. Alternatif manual:

```sh
xattr -dr com.apple.quarantine /Applications/NotchBrowser.app
```

Opsi lebih luas `xattr -cr /Applications/NotchBrowser.app` menghapus semua extended attributes, bukan hanya quarantine. Tidak perlu menjalankan keduanya. Ini melewati pemeriksaan berbasis quarantine untuk app tersebut, bukan bukti bebas malware atau notarization. Homebrew tidak menjalankannya otomatis. Sesuaikan path jika memakai `--appdir` lain; lihat [panduan Gatekeeper](../homebrew.md#peringatan-gatekeeper).
