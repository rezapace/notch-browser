# NotchBrowser v0.6.0

## Perubahan

- Tab dan URL auto-hide setelah 800 ms; hover tepi atas halaman atau ⌘L untuk reveal. Menu View → Always Show Controls tersedia.
- Overlay kontrol menjaga viewport WebKit tetap stabil. Tema gelap diteruskan ke website yang mendukungnya.
- Sudut bawah expanded 28 pt, satu mask shell, ukuran halaman lebih besar jika layar memungkinkan, dan Dock kiri/kanan diperhitungkan.
- View tab dipakai ulang, notifikasi UI digabung, dan geometri identik tidak dihitung ulang.
- Store WebKit persisten bersama tanpa reset cookie/cache; konfigurasi popup WebKit tetap dipertahankan. Popup otomatis tanpa interaksi diblokir.
- Path absolut build SwiftPM dihapus dari binary distribusi. Build memeriksa path home/proyek sebelum signing.
- Checksum DMG selalu dibuat ulang; tambahan tes auto-hide, cache, cleanup tab, resource executable bare, dan probe performa.

## Validasi dan batasan

`./scripts/test.sh --bundle` dan `./scripts/dmg.sh` memverifikasi UI invariants, resource relocation, signature ad-hoc, dan DMG. [Probe performa](../performance.md) mengukur UI/proses utama saja, bukan skor Speedometer atau total RAM WebKit.

DMG release: **Apple Silicon (arm64), macOS 13+**. Build dari source mengikuti arsitektur host. Signing masih ad-hoc, belum notarized. Kontrol overlay menutupi 68 pt halaman sementara saat terlihat. Dark theme tidak memaksa website dengan warna terang. Hidden tab belum disuspend dan tab belum dipulihkan setelah quit.

Perbaikan binary baru tidak menghapus string path yang sudah terpublikasi pada aset v0.5.0. Source/tag/release lama tidak diubah otomatis.
