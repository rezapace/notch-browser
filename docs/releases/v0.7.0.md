# NotchBrowser v0.7.0

## Instalasi Homebrew

```sh
brew install --cask rezapace/notch-browser/notch-browser
```

Tap: [rezapace/homebrew-notch-browser](https://github.com/rezapace/homebrew-notch-browser). [Panduan Homebrew](../homebrew.md) mencakup update, uninstall, dan migrasi dari DMG manual.

## Perubahan

- Dukungan Homebrew Cask, generator cask dari DMG final, dan dokumentasi instalasi tap.
- Tab kosong memakai UI native; satu WebView cadangan dipanaskan sesudah constructor UI lalu diadopsi oleh navigasi normal pertama. Tidak ada prefetch website atau penghapusan cookie/cache.
- Pembaruan kontrol ditunda saat auto-hide, lalu diterapkan sekali ketika reveal. Layout dan nilai UI identik tidak dikerjakan ulang.
- Memilih tab aktif tidak mengubah fokus editor atau visibility halaman. Popup tetap langsung membuat WebView dengan konfigurasi WebKit asalnya.
- Flag `--diagnose-loading` mencetak timing numerik ke stderr, tanpa URL, isi halaman, header, cookie, atau teks error. Default mati; tidak ada file log otomatis.
- Pemilihan process pool eksplisit yang tidak berpengaruh pada macOS 13+ dihapus.
- Tes tambahan untuk lazy tabs, cadangan engine, input saat KVO berubah, popup, privasi timing, callback lama, dan loading HTTP loopback.

## Pengukuran dan batasan

[Probe lokal](../performance.md#pengukuran-pembanding): constructor UI 28,33 → 3,91 ms; 10 tab kosong memakai 1 WebView (termasuk cadangan), bukan 10. Pemanasan engine ditunda, tidak dihapus. First load fixture setelah idle sekitar 24–27 ms pada satu run per versi; bukan bukti website atau Speedometer lebih cepat.

Varian lazy penuh tanpa cadangan tidak dipakai karena first load fixture menjadi sekitar 99 ms. Halaman yang sudah dimuat tidak disuspend otomatis; formulir, audio, dan sesi tetap dipertahankan. Tab belum dipulihkan setelah quit.

DMG release: **Apple Silicon (arm64), macOS 13+**. Build dari source mengikuti arsitektur host. Signing ad-hoc, belum notarized; instalasi Homebrew tidak menonaktifkan Gatekeeper. Uji perangkat/visual tetap diperlukan.
