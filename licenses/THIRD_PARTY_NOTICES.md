# Komponen asal

- **Quantum** — https://github.com/duggal1/quantum. Dasar implementasi browser dan aset ikon diadaptasi dari Quantum; chrome kini disederhanakan. README asal menyatakan lisensi MIT, tetapi salinan sumber yang tersedia tidak menyertakan file LICENSE terpisah. Verifikasi notice copyright upstream sebelum redistribusi publik.
- **DynamicNotch** — https://github.com/govijr/DynamicNotch-MacOS. Source vendored berada di `Sources/NotchBrowser/Vendor/DynamicNotch.swift` relatif terhadap root proyek. Siluetnya dipakai oleh panel NotchBrowser; salinan source juga memuat modifikasi hover. Lisensi MIT lengkap dipertahankan di bawah dan dalam `licenses/DynamicNotch-MIT.txt`.
